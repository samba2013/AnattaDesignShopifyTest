# AnattaDesignShopifyTest
Anatta Design Shopify Test

Step for test:

1 - create .env file with two params filled with credentials:

SHOPIFY_ADMIN_SHOP=
SHOPIFY_ADMIN_ACCESS_TOKEN=

2 - install node modules:
    npm install

3 - run test:

    node app.js --name shirt
